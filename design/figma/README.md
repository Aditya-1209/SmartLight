# SmartLight UI design

[Open the Figma design](https://www.figma.com/design/Mkoq4J3qKHNk02IjLVbSjA?node-id=6-57)

Created 1 October 2026 in the user's Figma Drafts. No subscription or paid upgrade was selected.

## Deliverables

- **01 · Foundations:** charcoal, mint, warm-white and scene accent colours; Inter typography; reusable buttons, light cards, scene cards, toggles and navigation.
- **02 · Android:** seven 412 × 915 screens: room, scenes, scene editor, light controls, settings, scene saved and scene applied.
- **03 · Mac & Windows:** six 1440 × 1000 screens: room, scene gallery and scene editor for each desktop platform.
- Clickable navigation and scene creation walkthroughs. The lighting controls are visual specifications, not a live device connection.

The file uses editable native text, vector illustrations, auto-layout containers and component instances. No screenshot of a complete UI is used as the design itself. Screen typography was verified as Inter; structural checks found no image fills in the screens.

## Product decisions

- Keep the main navigation to My room, Scenes and Settings. Connection diagnostics live inside Settings.
- Use colour to preview white temperature or a scene's mood, with readable text labels alongside it.
- The desktop room view shows all three lights together. A scene editor places controls next to the scene summary.
- Saving a scene does not apply it. Apply is a separate action.
- Setup transfer describes connection transfer only. Custom scenes remain device-local, matching the existing app.
- Preserve all pairing data and saved connections. This task changes only the Figma design and these design records; it does not update the Flutter application or install an APK.

## Design records

The JavaScript files record the native Figma construction helpers. They require the Figma Plugin API and the component IDs in `state.json`; they are not application runtime code. They are not intended to be rerun blindly against the populated design file. The state files retain the created node IDs for targeted edits.

The final refinements and visual review were completed in the signed-in Figma browser after the Starter automated-tool quota was reached. The design remains editable on the free plan. See REVIEW.md for the completed review and prototype scope.

## Application implementation

SmartLight 2.5.0 implements this direction in the shared Flutter application. The original vectors are bundled under assets/design and Inter fonts under assets/fonts. Existing device/scene values remain dynamic; no illustrative Figma connection values are written into user storage. UI regression previews are generated by test/ui_design_test.dart with SMARTLIGHT_CAPTURE_UI=true. See VALIDATION.md for build and test results.
